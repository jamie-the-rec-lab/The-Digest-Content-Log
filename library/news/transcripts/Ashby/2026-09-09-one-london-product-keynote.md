## Key announcements

- **WhatsApp communication:** candidate messaging channel alongside texting
- **Scheduled Agents:** run on recurring schedules (e.g. weekly pipeline
  recaps, Friday calibrations), pausing only for human confirmation
- **Career Page Builder:** visual, template-based editor, targeting early
  2027 launch
- **Agentic Scheduling:** finds interview times, sends requests, confirms
  schedules; includes a Copilot mode that pauses for human confirmation
  before emails send; launching later in 2026 (per 2026-09-11 fact-check,
  only the Copilot mode pauses before sending -- do not generalize to all of
  agentic scheduling)
- **Ashby MCP:** connects Ashby data to external AI tools (ChatGPT, Claude,
  Cursor) respecting existing permissions, no data export required
- **AI Notetaker recording sharing:** share full recordings or clipped
  moments with links to specific timestamps
- **AI-assisted application review and report builder**
- **EU data center** planned for 2027

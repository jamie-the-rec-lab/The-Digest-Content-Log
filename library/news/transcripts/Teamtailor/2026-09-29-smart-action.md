## What was announced

Smart action is a new stage trigger. A recruiter describes the task in plain language and the AI applies it to every candidate who enters that stage.

## How it behaves, per the page

- Depending on the prompt it can add a comment, fill in a custom field, add or remove tags, or create a to-do. Each prompt should contain one action; add another Smart action for each additional task.
- It uses only the information a recruiter on the job would see: the resume, application answers, comments and application context. If that information is missing, the candidate's record stays unchanged.
- Existing custom field values are kept, and tags are added only when the candidate's information supports them.
- Comments explain what information was missing and where the AI looked.
- A "Verify" check reviews a prompt before saving: it flags requests the AI cannot act on, warns when a prompt asks for more than one action, and warns when a prompt could lead to biased decisions.
- Every run is recorded in the audit log.

## Availability

Smart action appears with other stage triggers once AI features are active on the account. The page does not say when or how AI features are activated, which plans include it, or any cost.

## Episode description

All our resources (community, live sessions, newsletter):
https://promptmates.beehiiv.com/

Recruiting teams are starting to build directly on top of their ATS.

In this session, Jason Miller shows how to connect the Greenhouse API to Make.com and use it to build a simple system that analyzes recruiting pipelines using AI.

We cover:

• What APIs actually are (in simple terms)
• What changed in the new Greenhouse API
• How to create API credentials inside Greenhouse
• How to connect your ATS to Make.com
• How to extract candidate, job and application data
• How to send ATS data to an AI model for analysis

Jason then demonstrates a practical build:

A pipeline analysis tool that automatically reviews recruiter pipelines, flags issues, and generates insights before your 1:1s.

This is a great example of how modern TA teams can start building their own recruiting tools using APIs, automation and AI.

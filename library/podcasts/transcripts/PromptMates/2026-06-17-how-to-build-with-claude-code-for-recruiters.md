## Actionable summary
**Guest:** Matt Parker, ex-Head of Talent at Fleek and now managing partner at the Move talent agency, back for a second Claude Code session, alongside co-host Jason Miller, who built several of the Prompt Mates open-source skills.  ·  **Show:** PromptMates, 17 Jun 2026
**Tags:** claude code, claude skills, building ai tools, competitive intelligence, ai agents, recruiter enablement

**When to use this:** You have Claude Code installed and want practical use cases, especially reusable skills and plan mode, rather than a one-off build.

**Big idea:** A Claude skill is just a reusable markdown file, and combining installable community skills with plan mode lets a non-coder produce shareable, branded outputs like a live competitor-hiring dashboard.

**Frameworks & plays:**
- A skill is a markdown file stored in Claude Code's commands folder; Jason demos a tiny "screenshot" skill invoked with /ss that pulls your most recent screenshots, and points to the Prompt Mates GitHub where you paste a skill URL to install it.
- Matt installs the Prompt Mates "Intel Mate" skill, which reads publicly posted job ads across boards like Ashby, Workday and Greenhouse to pull competitor roles, comp and locations, then visualises them as a branded interactive HTML dashboard.
- Plan mode is for ambitious, iterative builds: it reviews and asks clarifying questions before coding, effectively producing a PRD you keep refining; Matt's mistake early on was not editing the plan enough, so outputs disappointed.
- Jason warns the GitHub skills ecosystem is more like an Android store than iOS, so before running an untrusted skill or URL, ask Claude to scan it for anything malicious.
- Token discipline: crop screenshots tightly, use Sonnet rather than Opus for routine work, and Intel Mate is coded to leave salary blank when not posted and never to invent unknown answers.

**Data & benchmarks:**
- Metaview's Fillmore agent swarm reached out to 576 people for a director of sales role at a roughly 24 to 25% reply rate, spending about 8,000 dollars, and is priced at 10% of first-year pay on success only.
- Fillmore secured a final-round candidate via a referral: the agent contacted someone at Mistral who declined but named the number-one person they would recommend, and the agent autonomously created a task to reach out to her.

**Tools & prompts:**
- Fillmore began as Metaview's internal fork of Claude Code, re-aimed at recruiting, and runs entirely through Slack yes/no prompts once the ideal candidate profile is agreed.
- Dan McCarthy suggested in the chat labelling outputs as fact, inference or assumption, an idea adopted live.

**Steal this (do tomorrow):**
- Install one Prompt Mates skill by pasting its GitHub URL into Claude Code and run it on a live role.
- Use plan mode to draft a competitor-hiring dashboard you can show a hiring manager.

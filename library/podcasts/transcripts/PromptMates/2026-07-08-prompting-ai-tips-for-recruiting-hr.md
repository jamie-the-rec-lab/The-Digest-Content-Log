## Actionable summary
**Guest:** Dan McCarthy, Senior Talent Engineer at Zapier, who runs community calls in Prompt Mates and teaches AI foundations, alongside hosts Joe and Jason.  ·  **Show:** PromptMates, 08 Jul 2026
**Tags:** prompting, ai fundamentals, claude code, context window, ai agents, recruiter enablement

**When to use this:** You are vibe-coding tools without understanding the fundamentals like tokens, context windows and agents that make them work reliably.

**Big idea:** More context is not always better, because as the context window fills the model glances at the front and back, skips the middle, and starts hallucinating confidently, so awareness of tokens and windows is a core recruiter skill.

**Frameworks & plays:**
- Dan built free "no stupid questions" learning modules covering basics, API, terminal and MCP; a token is the smallest chunk of data, where "recruiting" is one token and "unbelievable" is three.
- Claude models can run a 1 million token context window while some are 200,000; Dan's Zapier setup already consumes 40,000 tokens from built-in MCPs before he types a word, so he starts new chats rather than reusing one window.
- Dan pushes repeated tasks into sub-agents, for example an Ashby sub-agent, because a sub-agent opens with a fresh context window and returns only the answer without filling your working window.
- Dan's recruiter setup gives each open role its own project folder with its own claude.md memory file, so context persists across weeks and a role can be handed to another recruiter as a single file.
- Jason's tip is to force Claude to compact before it decides to, building in checkpoints and saving to a memory file so you control what survives.

**Tools & prompts:**
- Joe's default opening prompt for any new strand of work is "tell me what you know about X" to see what context is already held and fact-check it.
- Jason built a command that scans all code for API keys before committing, prompted by realising Claude routinely asks users to paste keys into chat.
- Jason's "prompt surgery": when ChatGPT rejected long-working prompts after model-spec changes tied to New York and California legislation, he tested each paragraph in isolation and found changing the word "candidate" to "reader" fixed it.

**Data & benchmarks:**
- Jack and Jill's two-sided network reports a 40% response rate versus low public-sourcing rates, roughly 6,000 new candidate signups a week, and just under 300,000 people, including a recently placed VP of People at a unicorn payments company.

**Steal this (do tomorrow):**
- Run a context check before long builds and start a fresh chat rather than piling résumés into one window.

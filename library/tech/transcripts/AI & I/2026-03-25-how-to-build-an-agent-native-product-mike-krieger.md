## Actionable summary
**Guest:** Mike Krieger, Instagram Co-founder  ·  **Show:** AI & I, 25 Mar 2026
**Tags:** ai agents, ai product, product strategy, product design

**When to use this:** You are building a product and trying to decide whether to design for agents first or humans first, or both.

**Big idea:** Agent-native products require different design than human products. Agents need clear structured outputs, predictable APIs, and frictionless workflows. Agents will become your largest user cohort within three years.

**Frameworks & plays:**
- API-first design: if you build an API that agents can consume, you own both the human and agent market. If you design for humans only, agents will build wrappers.
- Structured outputs beat narrative: agents prefer JSON and clear schemas over prose and ambiguity.
- Latency matters to agents: 100ms response time is necessary. 5 second response time is acceptable for humans but unacceptable for agent workflows.

**Data & benchmarks:**
- Instagram-scale products will see agents become 50 percent of usage within two years.

**Contrarian take:**
- Designing for agents is not dystopian; it is efficient. Efficiency is a feature, not a bug.

**Steal this (do tomorrow):**
- Audit your top three product workflows. Could an agent use them without human translation?
- If yes, add an API layer if one does not exist.
- If no, identify the friction and fix it: maybe it is vague wording, maybe it is requiring human judgment in a place you could automate.
